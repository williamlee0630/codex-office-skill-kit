# 資料契約與核對流程

本文件的操作情境均為模擬教學。實際分析不得把模擬數值當真實業績。

## 檔案與計算

- CLI：`python scripts/run.py --input <CSV或XLSX> --output <新資料夾>`。
- CSV 必須為 UTF-8，第一列為不重複的欄名。XLSX 讀取啟用工作表，可用 `--sheet` 指定；只讀，不改原始檔。
- 空白列排除，缺漏不補零。有限數值占非空值 60% 以上才分類數值；ISO 日期優先識別為日期。小於 60% 的混雜欄位保留為文字，需 Codex 檢查業務意義。
- 數值統計為有效筆數、合計、平均、中位數、最小／最大與樣本標準差。單筆樣本標準差為 null。
- 四分位採 Python `statistics.quantiles(..., method='inclusive')`，小於四筆或 IQR 為零時不標記異常；其餘以 Q1−1.5×IQR、Q3＋1.5×IQR 判定。異常是檢查線索，不是錯誤結論。
- 完全相同的重複列仍保留並納入計算，報告顯示重複筆數。
- 分組：`--group-by category --value amount`。趨勢再加 `--date-column date`，以日期合計並排序。缺少有效數字／分組／日期的來源列號記錄在 JSON，日期缺漏不默認為今天。
- Excel 與 JSON 是靜態計算結果，修改資料後重新執行。來源公式作安全文字，未運算公式；不要把缺少公式快取當零。

## 圖表規則

優先順序為日期合計折線圖、分組合計長條圖、首個數值欄的等寬次數分布。有負值時保留零基準。單點不敘述成長或下降。日期／分組 PNG 最多呈現前 12 個，資料全集仍寫入 Excel／JSON。欄位縮寫只用於圖上標籤，完整欄位保留在報告。

## Codex 核對與觸發驗收

1. 從原始資料挑兩列回算合計；核對有效數、缺漏數、排除列號與日期期間。
2. 確認幣別、百分比、數量等單位。若同欄混有不同單位，先由 Codex 分組或請使用者提供單位，禁止直接當成可比較結果。
3. 以完整自然語言請求實際觸發技能，從原始 CSV 讀取、執行腳本並解釋來源。不能直接讀預先做好的 JSON 就宣稱通過語意驗收。
4. 開啟 PNG／Excel 檢查字型、標題、圖表及截字。只有 unittest 通過時，記錄「程式測試通過；Codex 觸發與原生 Excel 檢查待驗收」。

所有外來文字透過 `_office.safe_cell` 寫 Excel，避免公式注入。程式不連網、不刪除原始列、不發布。執行錯誤回傳非零與繁體中文訊息。
