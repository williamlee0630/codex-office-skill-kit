# 財務報表與對帳助理

## 直接啟動

只有 `$finance-assistant` 時，簡短問：「目前想編製財務報表、核對兩份帳務，還是分析預算／實際差異？請提供相關資料。」已有目的與附件就直接處理；沿用本段對話已知資訊，不重問功能選項。

接受 XLSX、CSV 與貼上文字帳務明細。不要要求使用者填 JSON、找腳本、手動讀 Skill 或執行指令。自由文字先由你整理為保留原文與來源列的本機 CSV；不可自行補缺漏金額或分類。只有明確要求示範、練習或測試才使用 [內附模擬資料](references/demo/input.json)；真實工作不默默套用。

## 完成工作

1. 依需求選報表、對帳或差異分析。從原始檔確認欄位、幣別、會計期間、借貸方向與科目分類。只有影響計算的必要資訊不足才詢問；其餘保留待確認並交付可完成的部分。會計準則未指定時，先交工作底稿，正式報表用途再確認。
2. 讀 [執行與欄位規格](references/workflow.md)，在本機準備內部欄位對照或任務設定。金額一定由腳本直接讀原始 CSV／XLSX 數值並以 Decimal 運算；不要把語言模型填好的報表 JSON 當作計算來源。依需要在工作區建立虛擬環境並安裝本 Skill 的 [依賴](requirements.txt)，不做全域安裝。
3. 以本 Skill 的 [執行資源](scripts/run.py) 處理來源；使用新的輸出資料夾。腳本只做可驗證運算；科目及變動原因的語意判斷由你核對原始資料，有證據才列為事實。
4. 開啟輸出並核對來源列、關鍵金額、借貸與資產負債差額；對帳檢查六類及一對一配對，差異百分比核對基準分母與零基準。Word 首先呈現對帳摘要與六類數量，接著列需確認交易的識別碼、幣別、雙方金額、差額方向與來源列；Excel 第一表提供同樣摘要，再回查分析結果及原始資料。差額定義為內部減銀行；不同幣別不合計。必要時補充來源支持的說明；不得用補造交易讓報表平衡。
5. 交付實際成果連結及簡短重點，說明期間、幣別、缺漏、未完成的核對。不得宣稱完成正式會計查核。

## 成果與限制

- 報表：`財務報表.xlsx`（損益、資產負債、核對摘要；僅在完整分類並通過期初期末核對時加現金流量表）。
- 對帳：`銀行對帳結果.xlsx`（確認、疑似、金額不符、內部缺漏、另一來源缺漏、疑似重複）；相同金額不能直接確認同一交易。
- 差異：`財務差異分析.xlsx`（基準、實際、差額、百分比、增減與異常），零分母留空並說明。
- 每次另產 `財務分析報告.docx`、程式計算紀錄 `finance-result.json`；工作簿均有原始資料、來源對照、計算依據與待人工確認。

主要交付為可讀 Word 與可核對 Excel，JSON 只供查證。全部檔案先在新的可寫位置產生，重新開啟並核對工作表、交易筆數、分類、識別碼及金額後才交付；既有成果不覆寫。發生檔案鎖定或 PermissionError 時改用新成果資料夾，不把僅有檔名當成功。「產檔可用」「計算核對」「原生 Office 開啟」「完整 Codex 互動」須分開記錄；尚有例外時明說帳務未全部對清，完成計算不等於正式會計查核。

保留原始帳本與負數沖銷；分開不同幣別和期間；不自動換匯、過帳、覆寫或上傳公司資料。來源含 Excel 公式時，需經確認的數值快照，避免使用過期快取。缺漏或不平衡資料只能交付有標記的部分底稿。

執行前與交付前讀取並遵循[辦公成果品質與交付](references/quality.md)，依情境先呈現結論、保留來源與未知，實際產檔後重新讀取核對，分開記錄原生開啟與完整互動。
