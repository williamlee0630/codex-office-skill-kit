# 教學模擬案例

只有明確要求示範／練習時讀取本資料。`demo/` 內有虛構公司的風險及正常服務合約，均標示「教學模擬資料」，不是法律範本或真實法律來源。

錄影可啟動 `$legal-reviewer`，提供 `風險服務合約.docx` 並說「我代表甲方，請檢查不合理條款並輸出風險與修訂建議」。Codex 應從原件做完整語意審查；法域與現行法條未查證時保留限制。再以正常服務合約比較結果，不應僅因同樣出現付款或賠償用語就判高風險。

內部程式展示（不需學員操作）：`scripts/run.py --input references/demo/input.json --output <新目錄>`。`normal-input.json` 對正常 DOCX；`pdf-input.json` 對風險文字型 PDF。預填 JSON 是固定迴歸測試的 Codex 分析快照，不能當作獨立 Codex 啟動或新文件語意審查證據。

`預期審查結果.md` 記錄預期風險及正常條款判斷；驗收時對照原始條款、輸出風險清單與具體修訂，不只檢查檔案存在。
