# 版本紀錄

## 1.1.0 — 2026-10-30

- 以日常辦公需求引導十個 Skill；單獨 $名稱即可開始，沿用完整需求及補答。
- 內部讀規則、環境檢查、資料、執行及實際產檔由 Codex 接手；可選未知不阻擋。
- 模擬教學只在明確要求時使用；每支技能攜帶獨立示範與格式依賴。
- 講義、README、安裝、版本及下載包同步；長技術內容預設收合。
- 收據非模擬標示與研究腳本網址來源措辭修正，回歸測試實際先失敗再通過。
- 程式、代理演練、真實 CLI 及未驗證完整流程分開揭露。

## 1.0.0 — 2026-10-23

- 首次發行十個獨立 Codex 辦公室技能、原創模擬資料與離線繁體中文講義。
- 本機產生 Markdown、CSV、DOCX、XLSX、PPTX 與資料圖表。
- 分別記錄程式驗證、結構驗證、產物檢查與待人工確認的 Codex 觸發行為。
- 不自動寄信、發布網站、推送或修改全域技能。
