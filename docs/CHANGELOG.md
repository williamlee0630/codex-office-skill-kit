郵件章改為讀取已連接 Gmail 的最近七天、最多二十封收件匣郵件並整理重點、待辦與本機草稿；三封模擬郵件保留收合備案。同步連接說明、錄影流程、首頁與離線講義。既有 email-assistant 已支援此來源，技能規則與程式未改，不需重新安裝。Gmail 真實帳號讀信尚未端到端實測，先前貼文測試保留為歷史。

九章改為完整自然語言提示詞、必要附件獨立下載與實際成果檢查；四章免附件、五章共七份附件。同步首頁、一次性安裝、30 分鐘錄影稿及打包清單。技能規則與運算功能保留，另修正 PNG 隱私掃描將壓縮像素誤當文字的問題。真實 Codex 結果與限制見最新驗收，沒有宣稱九項全面成功。
