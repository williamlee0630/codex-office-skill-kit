# v1.2.0 錄製示範準備

## 附件即用的學員流程（2026-11-01）

安裝工具包是一次性的準備；每次使用 Skill 不必重新安裝。
每段教學按「介紹工作情境 → 下載附件（如需要）→ 複製提示詞 → Codex 執行 → 開啟成果」進行。
直接使用各章「立即體驗」完整提示詞；郵件、簡報、商務文件、創意企劃不需附件。
收據、銷售分析、方案研究、合約審查及財務對帳，從各章按鈕下載工作輸入後拖曳進 Codex。
教學附件不是安裝檔；可以換成自己的資料，並同步修改情境、日期與模擬標示。
保留完整解壓、手動安裝與疑難排解備案。ZIP 拖曳安裝未逐環境驗證，不宣稱通用成功。
原有內部路徑、JSON、Python 指令與預期答案供維護者使用，不是主要示範流程。
研究主示範只比較兩份附件，不宣稱即時網路搜尋。財務主示範只做對帳，預算差異與報表編製留作進階練習。


使用工具包完整解壓後的專案技能，或複製完整技能資料夾到錄製用工作區。不要覆寫既有全域同名技能。課程主線只需啟動、附檔、展示成果，不讓觀眾操作 Python 或 JSON。

## 法務四分鐘

1. 開啟[法務章立即體驗](../handbook/chapter-09.html#try-now)，介紹從甲方角度初步審查服務合約的情境。
2. 點按下載 [模擬服務合約 DOCX](../examples/quickstart/模擬服務合約_甲方審查.docx)，拖曳進 Codex，複製並送出該章完整提示詞；不另外給預填分析或改用第二段提示詞。
3. 展示合約審查報告.docx、合約風險清單.xlsx、條款修訂建議.md。先看風險摘要，再對照原始條款位置及可協商修訂文字。
4. 核對未承諾法規已查證、未把高風險等同違法、未知天數及法域留待確認。可用 [文字 PDF](../examples/legal-reviewer/風險服務合約.pdf) 或 [正常合約](../examples/legal-reviewer/正常服務合約.docx) 做延伸對照。

[模擬預期結果](../examples/legal-reviewer/預期審查結果.md) 僅供教師事先核對；不交給 Codex 代替讀原件。實際語意審閱的風險數量可能與固定迴歸資料不同，必須以原文與判斷理由驗收。

## 財務四分鐘

1. 開啟[財務章立即體驗](../handbook/chapter-10.html#try-now)，介紹公司內部帳與銀行明細的對帳情境。
2. 分別下載 [模擬公司內部帳 CSV](../examples/quickstart/模擬公司內部帳務.csv) 與 [模擬銀行明細 CSV](../examples/quickstart/模擬銀行交易明細.csv)，一起拖曳進 Codex，再複製並送出該章完整提示詞。來源包含 TWD、USD 及跨期交易，全部保留並分開處理，不縮限為單一月份或幣別。
3. 開啟銀行對帳結果.xlsx，展示六種分類、來源列及差額；同額交易不直接確認，重複列與未匹配仍保留。
4. 開啟財務分析報告.docx，回查金額差異與待確認項目。主示範到這裡結束，預算差異與報表編製另作進階練習。

## 三十分鐘路線

3分鐘概念與安裝、14分鐘七個既有技能成果、4分鐘法務、4分鐘財務、4分鐘修改技能、1分鐘總結。網頁各章延伸自學時間不等於影片片長。
