# 客服案件交接 SOP｜原始教學輸入

請依以下完整教學模擬背景，撰寫「客服案件交接 SOP」，提供正式版與精簡版 Word 文件，讓客服同仁能直接閱讀使用。請只使用下列素材，不要讀取工具包內的其他模擬文件。請保留來源與待確認事項，不得增加沒有來源的公司制度。

背景：公司準備建立客服案件交接流程，解決輪班後不知道案件進度、重複回覆，以及客戶承諾遺漏的問題。讀者是第一線客服與客服主管；目前尚未指定客服系統，也未訂正式上線日期。

工作角色：原承辦客服整理資訊；接手客服確認已讀與接手；客服主管協調無人承接、權限不足或需要跨部門處理的案件。

流程：
1. 原承辦人在交班前整理尚未結案的案件，記錄案件編號、問題摘要、目前狀態、已採取的處理、客戶已確認的承諾、下一步，以及有來源的期限。案件編號沿用原系統，不另外虛構。
2. 將交接記錄放在公司核准的共用位置，通知接手客服；具體工具與資料夾位置尚待確認。
3. 接手客服檢查資訊是否完整，回覆已接手；有缺漏時列出待補項目，不把未確認事項寫成完成。
4. 急件或可能超過已承諾期限的案件，交由客服主管協調；主管決定後補記處理方式。
5. 案件完成後，由實際處理者補記結果與結案依據，保留交接記錄以供追查。

注意事項：只記必要客戶資訊，避免把個資貼到公開群組；不得自行新增折扣、退款或賠償承諾；回覆時限、保存年限、簽核層級及實際使用工具均未決，應標示待確認，不得補成既有制度。

正式版請包含文件標題、草案版本、目的、適用對象、角色、流程、注意事項、例外處理與待核准／待確認清單；版本是草案識別，不代表已核准或已上線。精簡版保留可執行的交接重點和重要限制，兩份都標示教學模擬草案。
