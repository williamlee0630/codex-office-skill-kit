# 財務助理錄影素材（教學模擬資料）

三組來源是原創虛構公司的模擬資料，不含真實交易或帳戶。金額均由原始表格實際讀取；`input.json` 為 Codex 的內部設定，學員不用開啟或填寫。

1. **銀行對帳**：啟動 `$finance-assistant`，提供 `reconciliation/internal.csv` 與 `reconciliation/bank.csv`，說「請核對這兩份教學模擬帳務，交付 Excel 與報告」。可展示正常識別碼匹配、金額不符、沒有流水號的疑似匹配、雙方缺漏、重複、負數沖銷、外幣、零額、跨期與日期差異。預期六分類見 `reconciliation/expected.json`。
2. **預算差異**：提供 `budget/budget-actual.xlsx`，說「分析這份教學模擬預算與實際，標出異常」。展示零基準百分比留白、負數退款、四捨五入、分幣合計及缺漏資料保留；原因列待查。預期差額與百分比見 `budget/expected.json`。
3. **報表編製**：提供 `trial-balance/trial-balance.xlsx`，說「用這份教學模擬試算表編製損益與資產負債工作底稿」。展示收入 200,000、費用 100,000、損益 100,000、資產 350,000＝負債 50,000＋原始權益 200,000＋本期損益 100,000。缺少現金流量明細，因此不假造現金流量表。預期見 `trial-balance/expected.json`。

每次產出財務分析報告 DOCX、對應 Excel（含原始資料、來源對照、計算依據、待確認）及程式計算紀錄。錄影先開分析結果，再用來源列與計算依據驗算一筆。`verify_expected.py` 以獨立公式檢查三組預期結果；實際輸出仍須另跑正式腳本驗收。
