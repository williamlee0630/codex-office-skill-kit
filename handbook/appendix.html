    01下載與安裝

    技能可長期用於日常工作。安裝並載入後，送出 $技能名稱，依引導提供素材、必要時補答，再開啟成果。完整包保留離線講義、技能與另外選用的模擬教學；技能包可帶到一般工作區。

    安裝說明 · 版本、SHA-256 與內容清單

    技能教學啟動名稱工作用途
    智慧郵件處理助理$email-assistant辨識需要回覆與執行的郵件，整理每日待辦，產生不同語氣的回覆草稿。
    會議紀錄整理助理$meeting-assistant從討論找出重點、已確認決議與待辦，保留負責人、期限及未解決問題。
    專案進度追蹤助理$project-tracker整合工作更新，區分完成、進行中、逾期與風險，追蹤前後決策變動。
    智慧週報生成器$weekly-report以工作紀錄整理成果、問題與下週計畫，產生精簡版與詳細版 Word 週報。

    AI 簡報製作助理$presentation-maker規劃商務簡報的資訊層級，產生 PPTX 與講者內容，檢查文字長度及版面。

    資料研究與調查助理$research-assistant規劃研究方向、比較文件來源與日期，產生附來源清單的研究報告。

    02常見問題

    只輸入名稱就可以嗎？

    可以。只有名稱時，Skill 依用途詢問必要素材；已有工作內容時直接沿用。

    一定要會 Python 或 JSON 嗎？

    不用。環境檢查、讀規則、資料整理與執行都由 Codex 完成，不需長提示詞。

    可以直接貼文字嗎？

    可以，也可提供附件或可讀檔案，不必固定表單或檔名。

    會自動跑課程資料嗎？

    不會。只有明確要求示範、練習或指定範例時，才使用並標示模擬資料。

    資料沒填完會停止嗎？

    只缺可選人名、期限或成效數字時仍完成可用成果；真正影響結果的範圍與日期才補問。

    可以離線閱讀嗎？

    講義無外部執行依賴，可雙擊 HTML 離線閱讀；Codex 與初次取得套件仍依帳號及連線。

    03遇到問題，用日常語言說明

    直接說哪個檔案打不開、哪個欄位不對、哪項尚未確認。Codex 會沿用工作脈絡自行查來源、環境與錯誤；只有真正缺內容或權限時才具體請求協助。

    進階：給維護者｜技術排錯與維護入口
    維護項目檢查位置
    技能未載入或同名版本.agents/skills/ 下完整技能資料夾、agents/openai.yaml；由 Codex 核對實際載入來源，必要時重新載入。
    套件與命令各技能 scripts/requirements.txt、references/operation.md；可用環境優先，缺少才在工作區準備。
    來源或內部格式錯誤references/workflow.md；修正格式不補造事實。
    發行與部署tools/verify.py、build_release.py、check_release.py、build_site.py 及 Actions。

    04常用名詞

    名詞意思
    Skill可重複使用的工作規則與執行資源。
    來源本次實際提供、讀取並可追查的工作資料。
    待確認未知、不清楚或來源衝突，不用猜測填滿。
    模擬資料另外選用的教學與測試內容，不代表工作資料。
