    02常見問題

    我一定要會寫 Python 嗎？

    不需要先學 Python 或 JSON 語法。你只需下載解壓、在 Codex 開專案、貼完整工作需求，再開啟成果核對。實際產檔需要 Python 與格式套件，交由 Codex 或資訊同仁準備；手動命令放在「進階：給維護者」。

    網站可以離線，Codex 也能完全離線嗎？

    這份 HTML 講義不需要外部資源或伺服器。Codex 的實際使用仍依帳號、連線與環境。研究技能可只根據本機文件，不代表 Codex 執行環境本身完全離線。

    直接複製 SKILL.md 可以安裝嗎？

    請複製整個技能資料夾，包含 scripts 與 references。每支技能攜帶自己的共用模組，可獨立安裝；不要只留下說明而漏掉實際產檔腳本。

    是否需要 Gmail 或其他平台？

    本課程以本機模擬資料完成，不需要 Gmail 或額外 API 金鑰。沒有工具與實際讀取結果，就不會聲稱已連線。郵件預設只產生草稿。

    為什麼程式測試通過還要做觸發驗收？

    程式測試確認指定輸入下的計算與檔案行為。Codex 是否載入正確技能、理解原文與遵守來源限制，需要另外實際操作，不能用一個通過結果替代。

    我可以選擇全域安裝嗎？

    可以依你使用版本的官方規範自行選擇；全域安裝是額外步驟。本工具包預設留在專案 .agents/skills，不會自動覆寫個人技能。安裝前先檢查同名技能，保留完整資源與原版本。

    沒有 Office 也可以練習嗎？

    Markdown 與 CSV 可先用文字編輯器閱讀；DOCX、XLSX、PPTX 仍需用能開啟格式的相容軟體檢查。沒有實際開啟時，把該項目記為待人工驗收。

    03遇到狀況，先把實際問題交給 Codex

    你看到的狀況可以直接說的需求
    找不到技能或讀到別的版本請閱讀目前專案內的技能，回報實際路徑；不要覆寫全域技能。
    環境、套件或資料格式出錯請檢查目前環境與完整錯誤，列出已處理內容和需要資訊同仁協助的項目。
    找不到成果或無法開啟請回報真正執行的結果與產物位置，確認檔案實際建立，不只提供文字計畫。
    收據看不清、文件版面不對請指出哪些欄位或頁面需要人工核對；看不清保留未知，版面調整後重新產檔。
    複製沒有反應點選複製後若瀏覽器仍阻擋，可選取提示詞按 Ctrl+C；Mac 按 ⌘C。
    不用懂命令，也能請 Codex 排錯
    我在目前工具包遇到問題。
我想完成的工作：
使用的來源檔案：
我貼的工作需求：
目前看到的錯誤或結果：
我預期收到的成果：
請先讀取本專案相關檔案及實際錯誤，判斷原因並在目前工作區修正。環境細節請自行檢查；需要權限或人工核對就具體列出，不捏造缺漏資料。
    進階：給維護者｜原有錯誤名稱、命令與排錯紀錄
    狀況先做這件事
    找不到技能確認 Codex 開啟專案根目錄、.agents/skills/名稱/SKILL.md 存在且 frontmatter 正確。明確輸入 $技能名稱並要求回報實際載入路徑，必要時重新開啟 Codex。
    載入同名全域技能請 Codex 明確閱讀目前專案的 SKILL.md，核對絕對路徑。不自動刪除或覆寫全域技能；自有技能可使用清楚的新名稱。
    python 指令不存在請 Codex 檢查 Python 安裝與命令路徑，依組織規範準備後重新開終端機。也可確認是否能使用 py；不要只重跑同一失敗指令。
    ModuleNotFoundError使用 .venv\Scripts\python.exe -m pip install -r requirements.txt，產檔也用相同 Python。不要把套件裝在另一個環境後宣稱目前環境已可用。
    找不到 examples 或輸出目錄先確認執行位置在專案根目錄，路徑與技能名稱一致。輸出目錄會在實際執行成功後建立。
    資料格式錯誤對照本技能 SKILL.md 與範例欄位；保留錯誤訊息。不要用空字串、零或假人名填滿未知值來繞過檢查。
    一鍵複製沒有反應此站提供 file:// 複製替代方式。瀏覽器仍阻擋時會選取內容，按 Ctrl+C；Mac 按 ⌘C。
    收據看不清或無 OCR改用人工核對轉錄，將無法辨識的欄位留待確認。記錄實際辨識方式，不能聲稱已自動 OCR。
    簡報或 Word 版面不對先檢查本機字型與相容軟體，回到結構資料縮寫或分頁，再重建檔案；目視檢查結果需分開記錄。

    04遇到名詞時再查，不必先背

    名詞先這樣理解就能開始
    SkillCodex 可重複使用的工作說明書與工具。
    提示詞你貼給 Codex 的工作需求；可依目標、語氣、格式與來源調整。
    Word／Excel／PowerPoint本工具包實際產出的文件、報表與簡報，要用相容軟體開啟核對。
    待確認來源沒有說、看不清或有衝突，請保留未知，不能用猜的填滿。
    模擬資料教學情境，不代表真實公司或市場調查結果。
    進階：給維護者｜SKILL.md、JSON、CLI 與格式名詞
    名詞這份課程的意思
    SkillCodex 可發現、載入與遵循的工作指引及隨附資源。
    SKILL.md技能核心說明；開頭是 YAML name 與 description，後面是適用情境、流程與規則。
    JSON程式可讀取的結構資料。語意技能先由 Codex 從原文建立，不是讓腳本自行理解一切。
    CLI可貼到終端機執行的文字命令；也可以讓 Codex 代執行。
    DOCX / XLSX / PPTXWord／Excel／PowerPoint 常用檔案格式；本工具包會實際產生檔案。
    待確認來源未提供、無法讀取或仍有衝突的資訊；不是錯誤，也不能用猜測補滿。
    模擬資料為教學設計的虛構情境，不能引用成真實公司或市場研究結論。
