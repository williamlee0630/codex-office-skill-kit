    第 1 章：Codex Skill 基礎入門可離線閱讀 · 2026.10
    CHAPTER 01 / 實作課程

    Codex Skill 基礎入門

    安裝並載入技能，送出名稱，提供工作素材，再開啟成果。

    約 20 分鐘Windows / Codex日常工作工具

    01五步開始，日常工作直接用

    這十個 Skill 是可長期使用的日常辦公工具。課程是介紹與教學管道，技能執行時依你的實際工作處理。不需要先學 Python 或 JSON 語法，也不需要教 AI 讀取規則；環境、格式套件與產檔都由 Codex 接手，遇到具體權限限制才請資訊同仁協助。

    1. 安裝並載入技能下載工具包並完整解壓縮；依安裝說明放到 Codex 可發現的技能位置，載入後可在一般工作區使用。
    2. 送出 $技能名稱例如只送出下方的 $meeting-assistant。每支技能會依實際用途引導，不必先貼長提示詞。
    3. 依引導說明工作或提供素材可以直接貼文字、附檔或提供可讀檔案；已有需求與素材就直接執行，不重新選功能。
    4. 必要時補答只補會影響正確結果的資訊。Codex 會沿用前文接續，不要求重新貼完整需求或再確認開始。
    5. 開啟並核對成果檢查可開啟的檔案連結、來源、數字與待確認事項；直接用日常語言要求修改。

    02你的工作資料就是起點

    原始來源可以是郵件、會議筆記、工作紀錄、收據、報告或表格。無須固定檔名、表單或提示格式；Codex 會檢查可讀檔案、工作表與欄位。一般工作不會自動讀取工具包模擬資料來替代你的內容。

    技能內含自身規則、參考文件及執行資源，安裝時保留完整資料夾。工作成果預設另存到目前工作區 outputs 下的新資料夾，避免覆寫原檔及舊成果；最後依實際連結開啟。

    03安裝一次，之後直接使用

    完整解壓下載包，在 Codex 開啟解壓資料夾即可使用其中的專案技能。要帶到其他工作區，可複製完整技能資料夾到該工作區的 .agents/skills/，或依 安裝說明選用個人技能安裝。重新載入後送出技能名稱。

    Python 及格式套件由技能自行檢查；可用就沿用，缺少時在目前工作區準備。ZIP 沒有包入 Python。首次安裝可能需要網路或組織權限；限制會具體回報。講義可離線閱讀，Codex 使用仍依帳號與連線。

    進階：給維護者｜安裝結構、環境與同名版本排錯

    每支技能含 SKILL.md、scripts/run.py、scripts/requirements.txt、references/operation.md 與 workflow.md。不要只複製 SKILL.md。同名技能疑難由 Codex 自行檢查已載入來源，不要求使用者回報路徑，也不自動覆寫全域技能。

    04先送出技能名稱

    啟動會議技能
    $meeting-assistant
    對話角色日常工作示意
    Codex請提供會議筆記或逐字稿，貼上內容或提供檔案都可以。我會整理決議、提議、待辦與待確認事項。
    使用者請整理附件會議筆記；沒有寫負責人的地方先留待確認。
    Codex讀取筆記並實際產生會議紀錄，交付 Markdown 與 Word 連結及未決事項。

    也可以自然地說『幫我整理這份會議筆記』，技能仍可自動選用。已提供完整資料時不必先單獨啟動，也不會要求再選功能。

    05只問必要資訊

    情況處理方式
    沒有原始素材簡短請你提供需要的內容，不先讀示範答案。
    專案查核日或週報期間有歧義先從需求與來源判斷，仍不明確才問日期。
    沒有標題、檔名或一般版式採合理預設，不為此停止。
    人名、期限、成效數字未提供保留待確認，完成其餘可用成果。
    補充或修正資訊沿用前文與來源更新，保留舊成果，不要求重貼。

    06開啟成果，再用日常語言修正

    Codex 會自行讀取技能規則與必要參考、確認來源、檢查環境、整理有來源依據的內部資料並實際執行工具。它必須檢查檔案存在、內容可追查，交付可開啟連結；計畫、建議、中間資料或待補空殼不代表完成。

    你可以接著說『這項還在提議，請改回未定案』或『精簡成給主管看的版本』。同次修正應更新相關成果，保留原始資料。無法產出指定格式時須說明具體工具或權限限制。

    07區分三種驗證

    層次可證明與不能代替的事
    程式測試欄位、運算、格式、來源保護與打包；不證明代理真的遵循對話。
    代理行為演練讀規則後對具體案例的回應與處理；不等於正式安裝環境完整流程。
    真實 Codex 完整流程實際安裝載入、引導、補答、來源判讀、執行產檔與開啟核對。未做就標未驗證。

    另須分開記錄原生 Word／Excel／PowerPoint 畫面驗收。詳見 本版驗收報告；程式成功不能取代全部觸發驗收。

    08保留事實與授權邊界

    • 提議不能當決議；未知數字、人名與期限保留待確認。
    • 郵件預設只產草稿；寄送、上傳、發布與提交報帳依既有授權要求。
    • 清楚收據由 Codex 讀取核對；只問不清楚欄位。不同幣別不混加，疑似重複不直接刪。
    • 資料分析實際計算並使用業務欄位；創意評估保留主觀及待驗證；研究只引用實際讀過的來源。
    • 真實工作資料不會因使用工具包就變成模擬。只有明確要求示範時才使用並標示模擬資料。

    09開始一項工作

    核取方塊供本次閱讀自行檢查；重新開啟頁面會重設，不會上傳或儲存個人紀錄。
