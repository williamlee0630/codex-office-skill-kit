    發票與收據整理助理

    從收據保留可核對的欄位、按幣別統計，讓不清楚和可能重複的資料留在檯面上。

    約 30 分鐘Windows / Codex模擬資料練習receipt-organizer

    01這個 Skill 解決什麼問題

    報帳最容易出錯的地方，是看不清的數字被當成確定值，以及不同幣別被加成一個沒有意義的總額。這個技能整理收據欄位、保留來源，並用程式做可核對的分類與金額統計。

    圖片與掃描 PDF 需要實際視覺辨識、可用 OCR 或人工轉錄。這套 Python 腳本不冒稱具備 OCR；無法讀出的日期、金額或店家名稱維持待確認，不能靠常見價格推測。

    可能重複的收據會被標示，原始紀錄仍保留。沒有經過人工確認前，不靜默刪掉其中一筆，也不把不同幣別直接相加。

    02哪些員工適合使用

    • 行政與財務窗口：需要將多張收據整理成可以核對的報帳明細。
    • 業務與差旅人員：要區分交通、餐飲、辦公用品等支出，保留幣別。
    • 覆核人員：需要看見待確認金額與疑似重複資料，回到原始憑證判斷。技能輸出不能取代公司的正式報帳規則。

    先選一件你熟悉的日常工作練習，因為你越清楚原始內容，就越能看出摘要是否漏掉重要限制、誤解狀態，或新增了來源沒有的資訊。

    本章資料放在 examples/receipt-organizer/，成果放在 outputs/receipt-organizer/。請 Codex 自行確認環境；Python 與格式套件需要備妥，但你不需要先學語法。

    06完整操作步驟

    1. 先看憑證，再看轉錄開啟唯一一張模擬收據的 PNG 與 PDF，核對 R1。請 Codex 說明目前能使用的圖片或 PDF 讀取方式，沒有辨識能力就由你人工核對，不能假稱 OCR 成功。
    2. 核對必要欄位每筆檢查日期、店家、總額與幣別。缺少金額不能填零；幣別未知就保持未知，不拿電腦地區設定代替。R2 至 R5 的依據是模擬清單，不是原圖。
    3. 確認分類及疑似重複分類以品項與用途為依據，不確定則待確認。R2 疑似重複於 R1，只能標示，不靜默刪除。PNG 與 PDF 是同一張憑證，也不能算兩筆。
    4. 請 Codex 產生報帳表把已看清的欄位告訴 Codex，由它整理並產生 Excel；看不清或不確定就留下待確認，不要求你填寫轉錄格式。不同幣別各自合計。
    5. 在 Excel 與來源間回查開啟 receipts.xlsx，核對 5 筆明細、分類、幣別小計與待確認項。不要把含疑似重複資料的合計直接當成已核准報帳金額。

    09常見錯誤與解決方式

    發現的問題怎麼處理
    圖片打不開或沒有 OCR 工具請 Codex 回報限制，改用你逐欄核對的轉錄 JSON。這是可接受的替代流程，但驗收紀錄必須寫『人工轉錄』。
    台幣和外幣被加在一起先確認 currency 欄位，再依幣別重建統計。沒有來源匯率就不換算，也不假設所有 $ 都是相同幣別。
    重複項目不見了檢查是否被自行刪除。恢復原始紀錄，標為疑似重複並請人核對，報帳前再決定是否排除。

    如果腳本顯示輸入不符合格式，先請 Codex 對照本技能 SKILL.md 的契約修正資料。不要刪除檢查或把未知欄位亂填成確定值來通過。需要排錯時，保留實際錯誤訊息與使用命令。
