    AI 簡報製作助理

    從可核對的資料走到真正的 PowerPoint，讓每頁有重點、每個結論有出處。

    約 35 分鐘Windows / Codex模擬資料練習presentation-maker

    01這個 Skill 解決什麼問題

    文件能寫得很完整，投影片卻需要讓人快速抓住重點。這個技能先決定受眾、目的與簡報主線，再把資料分成有標題、有重點與有講者說明的頁面。

    每頁以一個主要訊息為原則，將細節放在講者說明，避免把整份報告貼進一個文字框。來源未支持的市場規模、業績或成功率，不能為了簡報好看而加入。

    交付物必須是真正可開啟的 PPTX。程式文字長度檢查可以阻擋明顯過長內容，實際字型替換、行距與畫面仍需要開啟 PowerPoint 檢視。

    02哪些員工適合使用

    • 業務、企劃與專案窗口：要把現有報告轉成主管或客戶看得懂的簡報。
    • 內部講師：需要清楚的章節、重點及講者提示。
    • 簡報審閱人：希望追查每個數字與決策依據。這個技能協助產檔，對外使用前仍需確認資料權限與事實。

    先選一件你熟悉的日常工作練習，因為你越清楚原始內容，就越能看出摘要是否漏掉重要限制、誤解狀態，或新增了來源沒有的資訊。

    03所需資料與準備步驟

    準備 source.md 的模擬事實，並告訴 Codex 簡報聽眾與目的。範例要做成可開啟的 PowerPoint 及講者說明；你不需先規劃程式用的頁面資料。

    本章資料放在 examples/presentation-maker/，成果放在 outputs/presentation-maker/。請 Codex 自行確認環境；Python 與格式套件需要備妥，但你不需要先學語法。

    進階：給維護者｜輸入契約、來源位置與準備細節

    閱讀 source.md 的模擬簡報需求與事實，再看 deck.json 的頁面結構。準備受眾、簡報目的、頁面標題、重點、講者說明與來源。不需要準備 API 金鑰；本機產檔需有 python-pptx，已包含在 requirements.txt。

    06完整操作步驟

    1. 固定簡報目的與聽眾先請 Codex 用一句話說明這份簡報希望聽眾理解或決定什麼。從 source.md 取出明確事實與待確認事項。
    2. 檢查頁面主線閱讀每一頁標題，看標題能否連成完整敘述。將背景、現況、問題與下一步安排好，不必為每一段原文各做一頁。
    3. 把重點與講者內容分開投影片只放必要重點，較長的解釋留在 notes 或講者稿。要求 Codex 保留每頁來源，未知數字不能變成圖表。
    4. 讓 Codex 產檔並調整長文字請 Codex 備妥頁面內容、實際產生 PPTX 並執行檢查。內容過長就請它摘要或拆頁，保留事實與來源後重建。
    5. 開啟簡報做畫面驗收用 PowerPoint 或相容軟體逐頁檢查標題、文字框、講者內容、頁序及特殊字元。程式檢查通過仍不能直接宣稱所有字型與版面已目視通過。
    進階：給維護者｜原有詳細操作與結構資料流程

    2. 檢查頁面主線閱讀每一頁標題，看標題能否連成完整敘述。將背景、現況、問題與下一步安排好，不必為每一段原文各做一頁。
    3. 把重點與講者內容分開投影片只放必要重點，較長的解釋留在 notes 或講者稿。要求 Codex 保留每頁來源，未知數字不能變成圖表。
    4. 產生 PPTX 並處理長文字以核對過的 deck JSON 執行腳本。如果出現文字過長診斷，先摘要或拆頁，再重跑；不降低字體到難以閱讀來硬塞內容。

    07用模擬資料完成一次實作

    完整實作只需把第 5 節的整段參考提示詞貼入 Codex。請它從本章原始來源開始，完成環境檢查、整理與實際產檔；不要停在摘要或操作計畫。Codex 若提出缺漏，先核對來源，再決定補資料或保留待確認。

    1. 貼需求並等候實際產檔使用本章模擬來源；讓 Codex 自行處理資料格式與工具執行。保留它回報的技能路徑與結果。
    2. 開啟第 8 節列出的成果核對檔案是否存在且能開啟，抽查一項已知事實與一項未知欄位，再對照下方預期摘錄。
    3. 用日常語言提出修正例如『這件事仍在提議，請保留未定案，重建所有版本並列出改動』。同一次修正的版本要一致。

    09常見錯誤與解決方式

    發現的問題怎麼處理
    只拿到簡報大綱要求執行本技能的 run.py 並回報實際 PPTX 路徑。檢查 requirements.txt 已安裝，不把貼上副檔名當產檔。
    長文字被程式拒絕依診斷把一頁拆成兩頁或將說明移到講者稿，維持原事實後重跑。不要刪掉來源與必要條件。
    開啟後某些文字換行不對可能是本機字型或相容軟體差異。回到來源頁面內容調整長度，再產檔與目視確認；記錄實際開啟軟體。

    如果腳本顯示輸入不符合格式，先請 Codex 對照本技能 SKILL.md 的契約修正資料。不要刪除檢查或把未知欄位亂填成確定值來通過。需要排錯時，保留實際錯誤訊息與使用命令。

    10延伸練習與驗收清單

    先複製原始模擬資料，再請 Codex 加入一個明確標示模擬的變動或缺漏，用相同需求重新產檔。也可調整讀者、語氣或呈現格式，核對新舊成果是否保留相同事實與未知規則。

    進階：給維護者｜本技能延伸練習的細節

    在 deck.json 的複本加入一頁過長的模擬內容，先觀察程式診斷，再分頁修正。比較兩版：聽眾能否讀得懂、講者稿是否仍保留細節，以及每個事實是否都能回到來源。

    核取方塊供本次閱讀自行檢查；重新開啟頁面會重設，不會上傳或儲存個人紀錄。
