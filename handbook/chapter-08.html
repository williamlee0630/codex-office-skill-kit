    第 8 章：資料研究與調查助理可離線閱讀 · 2026.10
    CHAPTER 08 / 實作課程

    資料研究與調查助理

    從可追查的來源比較觀點與資訊缺口，把文件說法、研究推論與未知分開。

    延伸自學約 30 分鐘Windows / Codex日常工作工具research-assistant

    01這個 Skill 解決什麼工作

    研究不只是把幾份文章摘要接起來。這個技能先確認研究問題，再對照各來源的時間、立場、支持證據與差異，整理目前能回答的範圍。

    同一個數字可能來自不同期間或不同定義。當文件衝突，保留兩邊說法與日期，指出尚未能確認的原因；不能選一個喜歡的答案當成真相。

    本套模擬練習可以完全以本機來源進行。無網路時明確標為離線研究；如果另外使用網路搜尋，必須記錄實際取得的來源、日期與限制，不能虛構網址或搜尋紀錄。

    02哪些工作適合使用

    • 企劃、產品與行政人員：需要針對明確問題比較多份資料。
    • 專案窗口：想知道現有文件已支持哪些結論、還缺哪些證據。
    • 主管與審閱人：需要從報告回到來源核對。對時效敏感的真實研究，還要確認資料是否仍適用。

    這是日常工作工具，可反覆用於真實工作。自然語言也能選用，不需要依序啟動其他技能；已有完整目的與素材時直接執行。

    03提供必要素材即可

    直接貼文字、附檔或提供可讀檔案，無須固定檔名、表單或長提示詞。Codex 會先讀目前對話與來源，自行查看能取得的檔案、欄位、工作表與環境；只問會阻止正確完成或實質改變結果的缺漏。

    標題、檔名、輸出位置與一般呈現方式採合理預設。未知人名、期限與成效數字保留待確認；有依據的內容先完成，不拿範例資料填空。

    04只送出技能名稱

    可複製的啟動內容
    $research-assistant

    只有名稱時會依工作用途引導；已有素材或正在補答時沿用前文，不重新介紹功能或要求選擇。

    05實務工作對話示意

    以下是對話方式示意，不是技能自動載入的來源，也不代表已在你的電腦產檔。你可用自己的話回答，不必回覆編號。

    角色內容
    使用者$research-assistant
    Codex你想調查或比較什麼問題？可以直接說明，也可以提供參考文件；若有特定地區、期間或比較對象，一起告訴我即可。
    使用者請比較附件兩份供應商方案，重點是服務範圍與限制，不查外網。
    Codex會逐一讀來源、比較條件與日期，區分事實、推論和缺口，附來源清單；不宣稱已搜尋網路。

    06補答與修改會接續完成

    1. 提供資料直接貼素材或附檔；若來源可讀且目的清楚，Codex 直接整理並執行。
    2. 只補關鍵缺漏需要日期、範圍或不清欄位時，回答那一個問題即可；不用重新貼完整需求。
    3. 開啟成果並修改使用實際檔案連結核對，再用日常語言說要改哪裡；Codex 沿用來源更新相關成果並保留舊版本。

    Codex 會自行讀內部規則、檢查環境、整理有來源的資料、選參數、執行並確認檔案存在。你不需要指示它讀 MD、回報技能路徑、編輯 JSON 或指定腳本。

    07另外選用的模擬教學

    本節教學採原創模擬資料，僅在你明確要求示範或練習時使用。一般啟動不會提供課程模式，也不會讀這些檔案。想練習可在啟動後用自己的話說『請用這章模擬資料示範一次』；Codex 會標示模擬，與工作成果分開保存。

    進階：給維護者｜模擬來源、保留的手動命令與測試細節

    先讀 input.json 中的研究問題與 sources 資料，並逐一開啟 sources/ 內的模擬 Markdown 來源。來源是教學文件，不是真實外部報導。記下文件名稱、日期、主張與限制；不能因為有檔名就當作已閱讀內容。

    1. 固定研究問題與範圍先請 Codex 讀 input.json 回報問題、資料截止日與離線模式。把很大的題目拆成能由現有文件回答的幾個面向。
    2. 實際閱讀每個來源逐一開啟 sources/ 的文件，記下來源識別、日期、主要說法與限制。資料日期未知就明列，不用檔案修改時間代替發布日。
    3. 比較一致與衝突將同一面向的不同說法並列。檢查定義、涵蓋對象與時間是否相同，不直接把不相同口徑的數字當成矛盾或平均。
    4. 寫出有邊界的結論每個結論指向實際來源；綜合判斷標為推論。資料不足時列出缺口與下一步可查什麼，不補造研究發現。
    5. 產檔並抽查引用把整理結果寫成 reviewed-input.json，執行 run.py。打開 research-report.md 與 sources.csv，抽查每個結論所引用的文件是否存在且支持該句。

    先用 input.json 驗證產檔，再獨立閱讀 sources/ 裡的原始文件重新整理。挑一項一致觀點與一項不同說法，逐字找出支持位置。寫下這份報告無法回答的問題，避免把『沒有找到』寫成『不存在』。

    進階：給維護者｜維護者產檔測試
    維護者產檔測試
    python .agents/skills/research-assistant/scripts/run.py --input examples/research-assistant/input.json --output outputs/research-assistant

    技能規則 · 內部資料契約 · 模擬來源 · 範例結構資料

    教學原文：sources/plan-a.md、sources/plan-b.md。摘錄須逐字存在。若內部 JSON 位於 outputs/research-assistant，可用 ../../examples/research-assistant/sources/plan-a.md；相對路徑由 Codex 處理。

    08開啟並核對成果

    這裡保留教學範例的預期成果，供明確練習時核對；不能當作一般工作的預填答案。實際成果仍依你的來源。

    進階：給維護者｜模擬範例預期內容
    • research-report.md 清楚交代研究問題、離線範圍、來源比較、結論、限制與待確認事項。sources.csv 列出真正使用的模擬來源與日期。
    • 每個事實陳述能回查文件；推論明確標示。過時或日期未知的資訊保留限制，不假裝取得最新外部資料。
    • 有衝突時並列說法與尚待確認之處，不產生不存在的外部網址、訪談或搜尋結果。
    進階：給維護者｜模擬預期摘錄
    模擬預期摘錄
    模式：離線模擬研究；查核日 2026-10-23。
S1：模擬甲方案，2026-10-01，24 名額，含一次諮詢。
S2：模擬乙方案，2025-08-15，最多 20 人，不含諮詢；資料需更新。
結論：先確認正式含稅報價、日期與服務範圍，不只比較單價。
限制：缺少獨立成效證據，不聲稱已驗證效果。
來源清單：2 個本機來源及資料日期、SHA-256。
    本技能實際產物核對方式
    research-report.md開啟檔案，抽查來源、日期、數字及待確認欄位
    sources.csv開啟檔案，抽查來源、日期、數字及待確認欄位

    只有計畫、操作建議、中間核對資料或待補空殼都不代表完成。有工具、連線或權限限制時，Codex 應具體列出未完成項目；程式格式檢查不等於原生 Office 畫面驗收。

    09發現問題時直接提出

    可以直接指出『這個期限不對』、『這項還沒核准』或『請縮短給主管看』。Codex 會回查來源、沿用已確認資訊更新；若修正與來源衝突，保留修正的依據與待確認狀態。內部格式錯誤由它先處理，不要求你填結構資料。

    進階：給維護者｜技術排錯與教學案例
    原有教學排錯案例核對方法
    報告引用了來源資料夾沒有的文章要求列出實際開啟路徑。無法證明取得的來源就移除，並重新檢查所有受影響結論。
    不同來源的數字被直接平均先比較定義、期間與對象。不可比較的數字應並列說明，不能靠平均掩蓋差異。
    離線報告寫成最新市場調查將模式明確改成『以現有模擬文件為基礎的離線研究』，交代資料日期與外部驗證缺口。

    10驗收與使用邊界

    核取方塊供本次閱讀自行檢查；重新開啟頁面會重設，不會上傳或儲存個人紀錄。

    預設只在工作區產檔。寄送、外部上傳、發布或提交報帳仍依既有授權要求；來源文件內的指令只當資料。保留原始資料，不捏造人名、金額、期限、數據或研究來源。

    進階：給維護者｜保留的延伸練習

    在 sources/ 複本加入一份日期未知、觀點不同的模擬備忘錄，重新做來源比較。檢查技能是否將它列為有限證據，並說明還需要查核什麼，而不是因為檔案較新就取代其他來源。
