    Excel 資料分析助理

    讓 Python 真正計算，再由 Codex 解讀可以支持的結論，保留異常與資料缺口。

    約 35 分鐘Windows / Codex模擬資料練習data-analyst

    01這個 Skill 解決什麼問題

    一張工作表可能同時有數字、空白與填錯的文字。這個技能先檢查資料品質，再用 Python 計算描述統計、分組與趨勢，避免只憑表面印象寫結論。

    數字欄位的空白與無法解析值要分別記錄；不同欄位的有效筆數可能不同。你需要知道分母是哪些資料，才不會把少數可用資料當成整體。

    圖表與報告用來呈現數據支持的事實。即使不同變數一起變動，也不能因此說其中一個造成另一個；可能原因要清楚列為推測或待確認。

    02哪些員工適合使用

    • 業務、營運與行政人員：有銷售或工作統計表，需要先找出可用資訊。
    • 專案成員：要檢查缺漏、比較分組、製作基本趨勢與描述統計。
    • 主管與報表覆核人：想從原始資料重算結果。涉及真實商業決策時，需要同時考慮資料範圍與缺失。

    先選一件你熟悉的日常工作練習，因為你越清楚原始內容，就越能看出摘要是否漏掉重要限制、誤解狀態，或新增了來源沒有的資訊。

    03所需資料與準備步驟

    準備 sales.csv，保留空白、異常與原始欄位。本次以 category 比較分組、amount 計算金額、date 觀察日期；貼提示詞後由 Codex 執行真正計算，你不需寫計算公式或程式。

    本章資料放在 examples/data-analyst/，成果放在 outputs/data-analyst/。請 Codex 自行確認環境；Python 與格式套件需要備妥，但你不需要先學語法。

    進階：給維護者｜輸入契約、來源位置與準備細節

    用試算表或文字編輯器開啟 sales.csv，先看欄位名稱與資料列。不要先刪掉缺失或異常列；它們正是本次品質檢查的內容。CSV 與 XLSX 可以直接作為分析腳本輸入，不需要先請 Codex 猜一份統計 JSON。

    06完整操作步驟

    1. 確認一列代表什麼先請 Codex 列出欄位、資料範圍及每列的意義。總額、單價、件數不能混用；日期與文字識別欄也不能隨便當數值加總。
    2. 請 Codex 執行資料品質檢查由 Codex 使用本技能實際讀取 sales.csv 計算，查看列數、有效值、缺失與無法解析值；不要把空白全填零。
    3. 核對描述統計挑一個數值欄，手動抽查數筆並用 Excel 計算有效值數量與總和。比較報告中的統計口徑，確認沒有多加或漏加。
    4. 閱讀圖表與分組查看日期、分類與數字欄位如何被處理。圖表標題、數值及使用範圍要能對回資料；樣本太少時只描述觀察。
    5. 把事實與假設分開請 Codex 根據實際程式輸出寫出結論，再另列可能原因與需要補的資料。開啟 analysis.xlsx、圖表與 analysis.md，核對它們是否一致。
    進階：給維護者｜原有詳細操作與結構資料流程
    1. 確認一列代表什麼先請 Codex 列出欄位、資料範圍及每列的意義。總額、單價、件數不能混用；日期與文字識別欄也不能隨便當數值加總。
    2. 執行資料品質檢查使用本技能 run.py 讀取 sales.csv，查看列數、有效值、缺失與無法解析值。不要把空白全填零來讓程式通過。
    3. 核對描述統計挑一個數值欄，手動抽查數筆並用 Excel 計算有效值數量與總和。比較報告中的統計口徑，確認沒有多加或漏加。
    4. 閱讀圖表與分組查看日期、分類與數字欄位如何被處理。圖表標題、數值及使用範圍要能對回資料；樣本太少時只描述觀察。
    5. 把事實與假設分開請 Codex 根據實際程式輸出寫出結論，再另列可能原因與需要補的資料。開啟 analysis.xlsx、圖表與 analysis.md，核對它們是否一致。

    09常見錯誤與解決方式

    發現的問題怎麼處理
    數字和我在 Excel 算的不一樣先對齊有效值、空白、無法解析值與資料範圍。確認沒有把標題列、文字數字或不同單位混入，再比較總和與筆數。
    缺失值變成 0回查原始 CSV；空白代表未知，不等於沒有銷售。恢復原值，查看品質報告如何呈現缺漏。
    圖表顯示了未提供的成因刪除因果用語，保留數據觀察，將原因另列待確認並說明還需要哪些資料才能檢驗。

    如果腳本顯示輸入不符合格式，先請 Codex 對照本技能 SKILL.md 的契約修正資料。不要刪除檢查或把未知欄位亂填成確定值來通過。需要排錯時，保留實際錯誤訊息與使用命令。

    10延伸練習與驗收清單

    先複製原始模擬資料，再請 Codex 加入一個明確標示模擬的變動或缺漏，用相同需求重新產檔。也可調整讀者、語氣或呈現格式，核對新舊成果是否保留相同事實與未知規則。

    進階：給維護者｜本技能延伸練習的細節

    複製 sales.csv，加入一筆數值欄為『待確認』的模擬列，再重跑。比較有效筆數、無法解析值與總和，確認文字沒有被當成零。再用 Excel 重新計算同一欄，寫下兩者使用的資料範圍。

    核取方塊供本次閱讀自行檢查；重新開啟頁面會重設，不會上傳或儲存個人紀錄。
