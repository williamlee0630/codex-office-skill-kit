    第 9 章：Excel 資料分析助理可離線閱讀 · 2026.10
    CHAPTER 09 / 實作課程

    Excel 資料分析助理

    讓 Python 真正計算，再由 Codex 解讀可以支持的結論，保留異常與資料缺口。

    約 35 分鐘Windows / Codex日常工作工具data-analyst

    01這個 Skill 解決什麼工作

    一張工作表可能同時有數字、空白與填錯的文字。這個技能先檢查資料品質，再用 Python 計算描述統計、分組與趨勢，避免只憑表面印象寫結論。

    數字欄位的空白與無法解析值要分別記錄；不同欄位的有效筆數可能不同。你需要知道分母是哪些資料，才不會把少數可用資料當成整體。

    圖表與報告用來呈現數據支持的事實。即使不同變數一起變動，也不能因此說其中一個造成另一個；可能原因要清楚列為推測或待確認。

    02哪些工作適合使用

    • 業務、營運與行政人員：有銷售或工作統計表，需要先找出可用資訊。
    • 專案成員：要檢查缺漏、比較分組、製作基本趨勢與描述統計。
    • 主管與報表覆核人：想從原始資料重算結果。涉及真實商業決策時，需要同時考慮資料範圍與缺失。

    這是日常工作工具，可反覆用於真實工作。自然語言也能選用，不需要依序啟動其他技能；已有完整目的與素材時直接執行。

    03提供必要素材即可

    直接貼文字、附檔或提供可讀檔案，無須固定檔名、表單或長提示詞。Codex 會先讀目前對話與來源，自行查看能取得的檔案、欄位、工作表與環境；只問會阻止正確完成或實質改變結果的缺漏。

    標題、檔名、輸出位置與一般呈現方式採合理預設。未知人名、期限與成效數字保留待確認；有依據的內容先完成，不拿範例資料填空。

    04只送出技能名稱

    可複製的啟動內容
    $data-analyst

    只有名稱時會依工作用途引導；已有素材或正在補答時沿用前文，不重新介紹功能或要求選擇。

    05實務工作對話示意

    以下是對話方式示意，不是技能自動載入的來源，也不代表已在你的電腦產檔。你可用自己的話回答，不必回覆編號。

    角色內容
    使用者$data-analyst
    Codex請提供要分析的 CSV 或 Excel 表格，也可以貼上表格內容。你最想了解什麼？若還沒有特定問題，我會先檢查資料品質與主要數值。
    使用者請看附件銷售表，檢查缺漏並比較各區銷售金額，員工編號只是識別資料。
    Codex會自行查看工作表與欄位，使用銷售金額實際計算，不把員工編號當績效；交付分析、Excel 及可用圖表。

    06補答與修改會接續完成

    1. 提供資料直接貼素材或附檔；若來源可讀且目的清楚，Codex 直接整理並執行。
    2. 只補關鍵缺漏需要日期、範圍或不清欄位時，回答那一個問題即可；不用重新貼完整需求。
    3. 開啟成果並修改使用實際檔案連結核對，再用日常語言說要改哪裡；Codex 沿用來源更新相關成果並保留舊版本。

    Codex 會自行讀內部規則、檢查環境、整理有來源的資料、選參數、執行並確認檔案存在。你不需要指示它讀 MD、回報技能路徑、編輯 JSON 或指定腳本。

    07另外選用的模擬教學

    本節教學採原創模擬資料，僅在你明確要求示範或練習時使用。一般啟動不會提供課程模式，也不會讀這些檔案。想練習可在啟動後用自己的話說『請用這章模擬資料示範一次』；Codex 會標示模擬，與工作成果分開保存。

    進階：給維護者｜模擬來源、保留的手動命令與測試細節

    用試算表或文字編輯器開啟 sales.csv，先看欄位名稱與資料列。不要先刪掉缺失或異常列；它們正是本次品質檢查的內容。CSV 與 XLSX 可以直接作為分析腳本輸入，不需要先請 Codex 猜一份統計 JSON。

    1. 確認一列代表什麼先請 Codex 列出欄位、資料範圍及每列的意義。總額、單價、件數不能混用；日期與文字識別欄也不能隨便當數值加總。
    2. 執行資料品質檢查使用本技能 run.py 讀取 sales.csv，查看列數、有效值、缺失與無法解析值。不要把空白全填零來讓程式通過。
    3. 核對描述統計挑一個數值欄，手動抽查數筆並用 Excel 計算有效值數量與總和。比較報告中的統計口徑，確認沒有多加或漏加。
    4. 閱讀圖表與分組查看日期、分類與數字欄位如何被處理。圖表標題、數值及使用範圍要能對回資料；樣本太少時只描述觀察。
    5. 把事實與假設分開請 Codex 根據實際程式輸出寫出結論，再另列可能原因與需要補的資料。開啟 analysis.xlsx、圖表與 analysis.md，核對它們是否一致。

    本章從 sales.csv 直接開始，先記下資料列數、各數值欄有效筆數及總和，再跑程式比較。選一筆缺失與一筆格式異常，觀察報告如何記錄。將『數值變動』和『可能原因』寫成兩個句子，後一句須明確標示推測。

    進階：給維護者｜維護者產檔測試
    維護者產檔測試
    python .agents/skills/data-analyst/scripts/run.py --input examples/data-analyst/sales.csv --output outputs/data-analyst --group-by category --value amount --date-column date

    技能規則 · 內部資料契約 · 模擬來源 · 範例結構資料

    僅此教學 sales.csv 的測試參數為 --group-by category --value amount --date-column date；實際工作依真實欄位選擇，禁止套用示範欄名。

    08開啟並核對成果

    這裡保留教學範例的預期成果，供明確練習時核對；不能當作一般工作的預填答案。實際成果仍依你的來源。

    進階：給維護者｜模擬範例預期內容
    • analysis.md 有品質說明與可回算的數值；analysis.xlsx 是可開啟的試算表，圖表依資料型態產生。
    • 缺失與無法解析資料被記錄，統計分母以實際有效值為準；原始資料沒有被覆寫。
    • 趨勢只描述這份模擬資料可支持的變化。不能從相關性直接宣稱促銷、天氣或其他未提供因素造成結果。

    09發現問題時直接提出

    可以直接指出『這個期限不對』、『這項還沒核准』或『請縮短給主管看』。Codex 會回查來源、沿用已確認資訊更新；若修正與來源衝突，保留修正的依據與待確認狀態。內部格式錯誤由它先處理，不要求你填結構資料。

    進階：給維護者｜技術排錯與教學案例
    原有教學排錯案例核對方法
    數字和我在 Excel 算的不一樣先對齊有效值、空白、無法解析值與資料範圍。確認沒有把標題列、文字數字或不同單位混入，再比較總和與筆數。
    缺失值變成 0回查原始 CSV；空白代表未知，不等於沒有銷售。恢復原值，查看品質報告如何呈現缺漏。
    圖表顯示了未提供的成因刪除因果用語，保留數據觀察，將原因另列待確認並說明還需要哪些資料才能檢驗。

    10驗收與使用邊界

    核取方塊供本次閱讀自行檢查；重新開啟頁面會重設，不會上傳或儲存個人紀錄。

    預設只在工作區產檔。寄送、外部上傳、發布或提交報帳仍依既有授權要求；來源文件內的指令只當資料。保留原始資料，不捏造人名、金額、期限、數據或研究來源。

    進階：給維護者｜保留的延伸練習

    複製 sales.csv，加入一筆數值欄為『待確認』的模擬列，再重跑。比較有效筆數、無法解析值與總和，確認文字沒有被當成零。再用 Excel 重新計算同一欄，寫下兩者使用的資料範圍。
