    日常使用與教學安排

    審閱重點課程安排
    課程目標讓沒有程式基礎的學員，能用自然語言交代工作，取得實際檔案，並依來源核對事實、數字與待確認事項。
    九個技能用途郵件、收據、簡報、商務文件、資料分析、創意企劃、來源研究、法務審查、財務對帳；下方各卡片可直接進入對應實作。
    操作方式安裝並載入技能 → 送出 $技能名稱 → 依引導說明工作或提供素材 → 必要時補答 → 開啟並核對成果。已有完整需求時直接處理。
    可帶走的教材完整 ZIP 內有 13 頁離線講義、九個技能、模擬來源與範例成果、安裝及維護文件。另提供技能包及練習資料包。
    環境與人工確認限制產檔確實需要 Python 與格式套件，由 Codex 或資訊同仁準備；Codex 使用依帳號及連線。學員不需先學語法。Office 版面、收據模糊欄位、未知資料與正式使用前的內容仍需人工確認。
    審閱狀態歷史開課方審閱版已更新為日常工作入口，未宣稱全面驗收。程式測試、Codex 觸發與語意、瀏覽器操作、Office 畫面各有邊界；請讀 實際驗收報告。

    Skill 是什麼？

    把 Skill 想成 Codex 隨時可讀的工作說明書：它約定這類工作怎麼處理、要保留什麼，以及交出哪些成果。你不需先理解程式架構，就能開始使用。

    只輸入技能名稱也能開始；技能會依實際用途請你提供必要素材。每次仍要檢查來源、未知欄位與實際檔案。

    怎麼安排學習？

    1. 讀第一章，安裝並載入要用的技能。
    2. 挑熟悉的工作，送出 $技能名稱。
    3. 讓 Codex 準備環境並產檔，再開啟成果回查原文。
    4. 需要改流程時，再讀第十一章；進階內容可稍後展開。
